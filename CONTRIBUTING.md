# Contributing

This list is generated from the directory at [123ofnet.com](https://123ofnet.com), so edits to the Markdown files here get overwritten.

- **Suggest a tool:** submit it at [123ofnet.com/submit](https://123ofnet.com/submit/) or open an issue with the name, website and one line on what it does. Every tool is checked before it's listed.
- **Something wrong or out of date?** Open an issue or email hello@123ofnet.com.
- **Own a listed tool and want it removed?** See [123ofnet.com/opt-out](https://123ofnet.com/opt-out/). Removal is free and needs no reason.

We don't accept pull requests that add affiliate or tracking links.
